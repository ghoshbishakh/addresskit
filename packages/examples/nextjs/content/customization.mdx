# Styling & Customization

AddressKit offers multiple levels of styling and customization: CSS class mappings, inline styles, component slot overrides, and compound primitives.

## Class Names & Theme Object

Pass a `classNames` object to style all sub-components with your CSS framework (such as Tailwind CSS):

```tsx
import { Address } from "@addresskit/react";

export function StyledAddress() {
  return (
    <Address
      value={address}
      onChange={setAddress}
      classNames={{
        root: "space-y-4 max-w-lg p-6 bg-white rounded-xl shadow border",
        field: "flex flex-col gap-1",
        label: "text-sm font-semibold text-gray-800",
        required: "text-red-500 font-bold ml-1",
        input: "w-full px-3 py-2 border rounded-md text-sm focus:outline-none focus:ring-2 focus:ring-blue-500",
        select: "w-full px-3 py-2 border rounded-md text-sm bg-white focus:outline-none focus:ring-2 focus:ring-blue-500",
        error: "text-xs text-red-600 font-medium",
      }}
    />
  );
}
```

## Inline Styles Object

Pass a `styles` object for fine-grained CSS-in-JS or inline styling:

```tsx
<Address
  value={address}
  onChange={setAddress}
  styles={{
    root: { maxWidth: 480, margin: "0 auto" },
    label: { fontSize: 13, textTransform: "uppercase", letterSpacing: "0.05em" },
    input: { borderColor: "#e2e8f0", borderRadius: 6 },
    error: { color: "#e53e3e", fontSize: 12 },
  }}
/>
```

## Field Overrides

Override labels, placeholders, or requirements for specific fields without creating a custom provider:

```tsx
<Address
  value={address}
  onChange={setAddress}
  fieldOverrides={{
    line1: {
      label: "Street & House Number",
      placeholder: "e.g. 123 Main St, Apt 4B",
    },
    line2: {
      placeholder: "Building, suite, unit (optional)",
    },
  }}
/>
```

## Custom Component Replacement

Provide custom Input and Select components to render design system elements (such as shadcn/ui):

```tsx
import { Address } from "@addresskit/react";
import { Input } from "@/components/ui/input";

<Address
  value={address}
  onChange={setAddress}
  components={{
    Input: ({ field, value, error, onChange, disabled, readOnly }) => (
      <div className="space-y-1">
        <label className="text-sm font-medium">{field.label}</label>
        <Input
          value={value}
          disabled={disabled}
          readOnly={readOnly}
          placeholder={field.placeholder}
          onChange={(e) => onChange(field.id, e.target.value)}
        />
        {error && <p className="text-xs text-destructive">{error}</p>}
      </div>
    ),
  }}
/>
```
