# Getting Started

AddressKit renders dynamic, country-specific address forms in the frontend and validates, normalizes, and formats addresses in the backend.

## Installation

### Single Umbrella Package (Recommended)

Install all features under one package:

```bash
npm install addresskit
```

### Individual Packages

Install only the modules your application needs:

```bash
# Frontend React forms
npm install @addresskit/react @addresskit/core @addresskit/data

# Backend validation
npm install @addresskit/validation @addresskit/core

# Zod validation schema
npm install @addresskit/zod zod
```

## Quick Start (Frontend)

Render a country-aware form in 2 lines with zero configuration:

```tsx
import { useState } from "react";
import { Address } from "@addresskit/react";
import type { Address as AddressType } from "@addresskit/core";

export default function MyForm() {
  const [address, setAddress] = useState<Partial<AddressType>>({ country: "US" });

  return <Address value={address} onChange={setAddress} />;
}
```

The component automatically loads metadata for the selected country, updates required fields, adjusts labels (e.g. "ZIP Code" in US vs "Postal Code" in Canada), and clears invalid state or locality selections when switching countries.

## Quick Start (Backend)

Validate and normalize addresses in server actions, Node.js services, or edge workers:

```ts
import { validateAddress, normalizeAddress, formatAddress } from "@addresskit/validation";

const rawAddress = {
  country: "us",
  line1: "  1600 Amphitheatre Pkwy  ",
  locality: "  Mountain View  ",
  administrativeArea: "California",
  postalCode: "  94043  ",
};

// 1. Normalize address
const normalized = await normalizeAddress(rawAddress);
// Result: { country: "US", line1: "1600 Amphitheatre Pkwy", locality: "Mountain View", administrativeArea: "CA", postalCode: "94043" }

// 2. Validate address
const validation = await validateAddress(normalized);
if (!validation.valid) {
  console.error("Invalid address:", validation.errors);
}

// 3. Format address
const singleLine = await formatAddress(normalized, { singleLine: true, includeCountry: true });
// Result: "1600 Amphitheatre Pkwy, Mountain View, CA 94043, United States"
```

## Package Overview

| Package | Description |
| ------- | ----------- |
| `addresskit` | Convenience umbrella package re-exporting core, react, validation, and zod. |
| `@addresskit/core` | Headless engine, metadata parsing, formatting, normalization, and types. |
| `@addresskit/react` | React component `<Address>`, compound primitives, context, and headless hooks. |
| `@addresskit/validation` | Standalone backend validation, normalization, and formatting. Zero DOM dependencies. |
| `@addresskit/zod` | Zod schema integration for backend validation pipelines. |
| `@addresskit/react-hook-form` | `<AddressController>` and validation rules for React Hook Form. |
| `@addresskit/data` | Bundled country metadata for 256 countries. Lazy-loaded per country. |
| `@addresskit/providers-libaddressinput` | Google libaddressinput metadata provider. |
| `@addresskit/providers-dr5hn` | Provider with comprehensive state lists for 250 countries. |
